支援任何 OpenAI 相容的 Chat Completions 端點（DeepSeek、OpenAI、vLLM、Ollama、LM Studio…）。設定會寫入專案的 .env（已被 git 忽略、權限 600），並立即生效。

說明

  • 不填 Key 也能跑：估值會用規則後備（assumption_source = rules_fallback），結果仍然完整。
  • 本地端點（127.0.0.1／localhost）不需要 Key。
  • Key 只會回傳長度與末四碼，完整值不會出現在瀏覽器。
  • 測試連線會發送一次極小的請求，會計入你的 API 用量。
