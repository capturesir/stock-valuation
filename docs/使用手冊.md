# 系統功能及操作說明書（Stock Valuation v2.0）

> **免責聲明**：本系統產出之所有數據、模型估值與 AI 摘要均僅供研究與教學參考，**不構成任何投資建議**。官方理論價與各項財務指標均由本機 Python 引擎依公開來源與明列假設計算，不依賴大語言模型心算。

---

## 1. 系統總覽與核心原則

本系統是一套可部署於 Windows、macOS、Linux 的前後端分離股票研究與估值平台：

- **數據優先於 AI**：美股以官方 SEC XBRL 為主、Yahoo 交叉核對；港股採用 D11 免費來源（Yahoo＋年報 PDF 抽取與交叉核對），並以四層架構（原始層 → 申報層 → 標準層 → 檢查層）確保每個數字均可追回原文。
- **完全可重現**：v1 FCFF 引擎數值逐位元不變；每次估值與投資組合最佳化皆記錄當時數據版本、規則版本、調整方案版本與隨機種子。
- **多語言支援**：網頁介面、API 錯誤訊息、資料缺口說明、估值 Excel 工作簿與 Markdown 報告全面支援繁體中文（`zh-Hant`）、简体中文（`zh-Hans`）與 English（`en`）。

## 2. 安裝與初次啟動

完整安裝與疑難排解見 [`INSTALL.md`](../INSTALL.md)。

### 2.1 Docker 快速啟動（建議）
```bash
cp .env.example .env      # 設定 APP_SECRET_KEY 與 PostgreSQL 密碼
docker compose up -d --build
# 首次建立管理員帳號：
docker compose exec api python -m backend.app.cli create-admin
# 打開瀏覽器：http://localhost:8080
```

### 2.2 本機開發模式
1. 啟動 PostgreSQL 16（預設連線 `postgresql+psycopg://valuation:change-me@127.0.0.1:5432/valuation`）。
2. 後端：`.venv/bin/uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload`
3. 前端：`cd frontend && pnpm --filter @sv/web dev`（開啟 `http://localhost:5173`）

## 3. 用戶角色、品牌與系統設定

- **管理員（admin）**：
  - 帳號管理（新增、停用、重設密碼、指派角色）。
  - **品牌設定**：自訂系統名稱與淺色／深色 Logo（SVG／PNG，上限 512 KB），同步套用於頁首、登入頁、PWA 圖示、Excel 與 Markdown 報告頁首。
  - **數據來源設定**：填寫 SEC 規定的聯絡機構名稱與電郵（`User-Agent`）；啟動後即可自動同步任意美股財報。
  - **AI 設定與預算（D2、D9）**：全系統共用一把 OpenAI 相容金鑰（支援雲端或本地模型），設定單次／每月上限與模型價格表；未設金鑰時自動採「不用 AI」模式，計算功能照常運作。
- **一般用戶（member）**：
  - 享有獨立的私人觀察名單、投資組合、走勢比較組合、個人財報調整方案與私人問答對話；市場數據、財報數據與估值紀錄為全系統共享（D10）。
  - 於個人設定選擇介面語言、淺色／深色主題、顯示貨幣（D7）與預設再平衡頻率（D8）。

## 4. 觀察名單與市場數據累積

1. 在首頁「觀察名單」輸入股票代號（支援自動正規化：`2800` → `2800.HK`、`BRK.B` → `BRK-B`）。
2. 首次加入或查詢時，系統自動回補完整歷史未調整日線價格與公司行動（派息、拆股），並自行計算總回報與來源交叉核對。
3. **每日自動排程**：港股與美股收市後增量更新；若來源事後靜默修訂歷史價格，舊值永久保留於 `price_revisions`。
4. 管理員可於設定頁檢視每隻證券的交易日曆完整性檢查、來源缺失區段與 SEC 派息互核結果。

## 5. 財報數據、進階分析與調整方案

打開任一股票的 **「財報」** 分頁：

- **美股（SEC XBRL）**：打開分頁自動背景抓取申報清單、`companyfacts` 與近 12 年年報 XBRL instance（含按股份類別 EPS 與公司自訂科目），按行業自動套用「一般企業／銀行／保險」三套標準科目表。
- **港股（D11 免費來源）**：輸入 `0700.HK` 等港股代號後可同步 Yahoo 年度 IFRS 財報，並點擊 **「上傳港股年報 PDF 核對」** 直接解析中英文年報財務報表（自動辨識 `HK$'000`、`RMB million`、`人民幣百萬元` 等單位），與 Yahoo 逐項以 1% 容許誤差交叉核對，正式年報數字優先進入標準層。
- **檢視切換**：支援年度／季度／近十二個月（TTM）、最新（含重編）／首次公布、金額／共同比（佔營收或總資產%），點擊任一格即可檢視規則血統與可點擊原文連結。
- **杜邦分析與盈利質素**：自動展開 3 因子／5 因子 ROE 拆解，以及經營現金流／淨利、自由現金流／淨利、Sloan 應計比率與盈利質素評級（優良／尚可／偏弱）。
- **數據品質檢查**：每期顯示 A／B／C 等級與未通過之勾稽／跨來源檢查；「錯誤」級別未處理的財年不會靜默進入估值。
- **調整方案（D12）**：管理員維護全系統「中央方案」；用戶可複製為「個人方案」逐格調整並保留全部歷史版本；支援一鍵匯出含出處與調整留痕的 Excel／CSV。

## 6. 多方法估值與足球場圖

1. 點擊股票頁右上角 **「執行估值」**，選擇 AI 模式（不用 AI／輕量／標準／深度）與調整方案，即時透過 SSE 查看執行進度與累計費用。
2. 完成後於 **「總覽」** 與 **「估值」** 分頁檢視：
   - **五情境 FCFF DCF**：含 WACC、永續增長率 `g`、獨立驗算結果與資料缺口說明。
   - **多方法估值與足球場圖（Football Field）**：
     - **一般企業**：FCFF DCF（65%）＋ 相對估值（P/E、P/B、EV/EBITDA、EV/Sales，35%），並附 **反向 DCF** 顯示當前市價隱含的 5 年自由現金流複合增長率。
     - **銀行與保險（D5）**：自動顯示金融業 FCFF 警示橫幅，改以 **剩餘收益模型（RI，45%）＋ 二階段股息折現（DDM，35%）＋ 合理 P/B–ROE（20%）** 計算綜合理論價。
   - **一鍵下載**：直接匯出符合目前介面語言與品牌頁首的 **Excel 工作簿** 與 **Markdown 估值報告**。

## 7. 文件庫與附出處問答（D13）

打開股票頁 **「文件庫與問答」** 分頁：

1. 點擊 **「同步文件庫」**，自動納入該股近期 SEC 申報正文（10-K／10-Q／8-K）、最新估值報告與標準化財報摘要；亦可手動上傳港股年報 PDF、Markdown 或純文字研究筆記（上限 10 MB）。
2. 在對話區提問：
   - 系統先以 **PostgreSQL 全文搜尋＋向量餘弦 RRF 混合檢索** 找出最相關段落；涉及財報數字時直接呼叫標準層精確數值工具。
   - 每則回答均附可點擊出處（標明「文件庫」或「網上」與抓取日期）；若證據不足則明確拒答，不憑模型記憶編造。
   - 勾選「證據不足時允許上網補充」後，抓到的公開網頁會自動歸檔入庫並標註來源。

## 8. 統一新聞介面與 AI 任務（T1／T2／T7）

打開股票頁 **「新資訊」** 分頁：

- **統一新聞與公告（D4）**：自動彙整 SEC 申報（8-K／10-K／10-Q）、披露易公告與 Yahoo 新聞標題，全部附可點擊原文連結。
- **一鍵產生 AI 建議**：
  - **T1（財報異常與重編審查）**：直接以檢查層失敗項與重編紀錄為輸入，不臆測數字對錯。
  - **T2（新聞與催化劑摘要）**：以統一新聞來源為輸入。
  - **T7（多方法估值與反向 DCF 解釋）**：整理綜合理論價、方法分歧與市價隱含增長預期。
- **100% 引用驗證與審查流程**：任何缺少可點擊網址或引用不在輸入中的建議均會被系統 100% 拒絕；用戶逐項決定 **「採用」／「忽略」／「重設」**，採用 T1 建議時可直接寫入個人調整方案並完整留痕。

## 9. 走勢比較、同業財報比較與投資組合最佳化

- **走勢比較（`/compare`）**：最多同時比較 10 條線（股票或已保存投資組合）與指定基準，支援起點 100／回報率切換、勝負著色、相對強弱副圖、17 項 CFA 慣例績效指標、匯出 Excel／CSV，以及下方的 **「多家公司財報並排比較」**（含同業中位數）。
- **投資組合最佳化（`/optimize`）**：設定 2–10 檔資產上下限、顯示貨幣（D7）、再平衡頻率（D8）與綜合得分權重，以固定種子隨機抽樣＋SLSQP 精修計算效率前緣與樣本外檢驗；保存為「場景」後可隨時一鍵重算核對是否完全相同。

## 10. 備份與日常維護

- **資料庫備份**：定期執行 `pg_dump` 備份 PostgreSQL（包含用戶、觀察名單、原始／申報財報、文件庫、估值與最佳化場景）。
- **檔案卷備份**：同時備份 `APP_DATA_DIR` 下的 `raw/`（不可變原始財報檔）、品牌 Logo 與估值 Excel 檔案。
- **版本更新與測試**：開發與 CI 測試請執行 `scripts/dev.sh test`；詳細版本規範見 [`docs/versioning.md`](versioning.md)。
